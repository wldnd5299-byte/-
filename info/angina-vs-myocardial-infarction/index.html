I20 협심증과 I21 급성심근경색증 질병코드 및 보험 담보 분류표 비교

발행일: 2026-09-16

보험브릿지에 등록된 보험사별 약관 분류표를 기준으로 독립 질병코드 I20과 I21이 어떤 담보와 세부 분류표에 기재되어 있는지 비교합니다.

※ 확인 안내: 본 문서는 현재 보험브릿지에 등록된 손해보험사 약관 분류표 원본의 코드 기재 현황을 확인하기 위한 비교 자료입니다. 실제 보험금 지급 여부 및 세부 보장 요건은 계약자가 가입한 해당 상품의 약관과 계약 내용을 별도로 확인해야 합니다.

1. I20과 I21 질병코드 및 약관상 질병명

보험브릿지 약관 데이터베이스에 등록된 분류표를 전수 대조한 결과, 두 질병코드는 각각 다음과 같은 질병명으로 기재되어 있습니다.

질병코드 약관상 질병명 표기 등록 약관 내 기재 현황
I20 협심증 6개 보험사, 10개 담보 분류표에 총 14건 독립 코드로 기재
I21 급성심근경색증
(일부 약관은 '급성 심근경색증'으로 띄어 표기)		 5개 보험사, 8개 담보 분류표에 총 10건 독립 코드로 기재

* 상기 보험사 수, 담보 수, 레코드 수는 현재 보험브릿지 데이터베이스에 등록된 약관 분류표 기준입니다.

2. I20과 I21이 함께 기재된 담보 분류표

현재 등록된 약관 데이터 중 독립 코드 I20과 I21이 동일한 담보의 분류표 안에 함께 기재되어 있는 담보는 총 7개입니다.

DB손해보험 통합형심장질환(I/II) I20: 허혈심장질환(급성심근경색증제외) / I21: 급성심근경색증 약관 보기
DB손해보험 심장질환진단비(I/II/III) I20: 특정 I / I21: 특정 II 약관 보기

* 동일 담보 내에서도 두 코드가 하나의 세부 그룹으로 묶이거나, '특정질환 I'과 '특정질환 II'처럼 서로 다른 번호의 세부 보장 항목으로 분리되어 기재되는 방식이 확인됩니다.

3. I20 또는 I21이 개별 기재된 담보 분류표

이번 독립 코드 대조 과정에서 두 코드가 함께 나타나지 않고, I20 또는 I21 중 하나의 코드만 독립 코드로 확인된 담보 목록입니다.

4. 독립 코드와 범위 코드 기재 방식 확인

보험사 약관 원본에는 특정 코드를 개별 행으로 기재하는 독립 코드 방식 외에도, 여러 질병코드를 묶어 표기하는 범위 코드 방식이 함께 사용됩니다.

  • 독립 코드 기재: I20 또는 I21처럼 개별 코드가 독립 행으로 직접 표기된 형태입니다. (본 비교에서 다룬 I20 14건, I21 10건)
  • 범위 코드 기재: I20~I25(허혈성 심장질환 등) 또는 I21~I23과 같이 물결표(~) 기호로 구간을 표기한 형태입니다.
※ 본 비교의 통계 수치는 범위 코드를 포함하지 않고 약관 원문에 독립 코드로 기재된 항목만 산출한 결과입니다. 따라서 특정 담보에 I20 또는 I21이 독립 코드로 보이지 않더라도, 해당 약관에 I20~I25와 같은 범위 코드가 기재되어 있을 수 있으므로 약관 원문의 별표 구성을 직접 확인하는 것이 필요합니다.

5. 질병코드 검색과 보험사 약관 분류표 확인

보험브릿지에서는 등록된 주요 보험사의 담보별 분류표 데이터를 데이터베이스화하여 제공하고 있습니다.

질병코드 검색 기능 활용:

질병코드 검색 화면에서 I20 또는 I21을 입력하면, 본문에 정리된 담보 외에도 해당 코드가 기재된 보험사별 분류표 항목과 질병명을 실시간으로 직접 검색하고 원문 위치를 대조할 수 있습니다.
