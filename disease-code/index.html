질병코드 검색 및 보험 담보 분류표 찾기

한국표준질병사인분류(KCD) 질병코드 또는 질병명을 검색하여, 보험브릿지에 등록된 주요 보험사(DB손해보험, KB손해보험, 삼성화재, 메리츠화재, 한화손해보험, 롯데손해보험, 현대해상, 농협손해보험, 하나손해보험, 라이나생명, 삼성생명 등)의 암·뇌·심·수술비 등 125개 담보별 약관 분류표에서 해당 코드가 기재된 항목을 확인할 수 있습니다.

[안내] 검색 전 필독 안전 안내사항 (참고자료 확인)

본 검색 결과는 보험브릿지에 등록된 약관 및 담보별 분류표 원본에 해당 KCD 코드 또는 질병명이 기재되어 있는지를 단순 대조하여 보여주는 참고자료입니다. 검색 결과만으로 보험금 지급 여부 또는 실제 보장 여부를 판단할 수 없으며, 가입하신 개별 보험계약의 증권과 약관을 반드시 확인해야 합니다.

질병코드 검색은 어떻게 사용하나요

진단서, 수술확인서, 입퇴원확인서 등 병원 서류에 기재된 한국표준질병사인분류(KCD) 기호(예: I20, I63, C50, M51, E11 등) 또는 질병 명칭(예: 협심증, 뇌경색증, 유방의 악성 신생물, 2형 당뇨병)을 검색창에 입력합니다. 영문 대소문자나 단순 공백 차이는 검색 도구 내에서 자동으로 인식되어 매칭됩니다.

검색 결과에서 무엇을 확인할 수 있나요

조회한 질병코드 또는 질병명이 현재 보험브릿지에 보존되어 있는 어떤 보험사, 어떤 담보(통합암, 뇌혈관질환, 허혈성심장질환, N대 질병수술비 등), 그리고 어떤 세부 약관 분류표에 포함되어 있는지를 계층 구조로 즉시 확인할 수 있습니다. 결과 카드의 [담보 분류표 보기] 링크를 통해 해당 보험사의 상세 담보 약관 테이블로 바로 이동할 수 있습니다.

질병코드 검색 예시

질병코드를 알고 있다면 검색창에 KCD 코드를 직접 입력해 보험브릿지에 등록된 보험사별 담보 분류표에서 해당 코드가 기재된 항목을 확인할 수 있습니다.

질병코드 검색 시 주의할 점

본 검색 시스템은 약관 원본 데이터에 해당 코드가 문자열로 존재하는지를 사실 기반으로 대조하는 도구입니다. 약관 규정상 범위코드(예: I20~I25)로 묶여 있거나 세부 하위코드(예: 소수점 코드)가 별도로 지정되지 않은 담보가 있을 수 있으며, 실제 보험금 지급 여부, 면책 기준, 감액 기간 등은 개별 가입 보험계약의 증권 및 약관 규정에 따라 최종 결정됩니다.
